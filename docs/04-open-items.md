# Open Items — สิ่งที่ยังค้างก่อนเริ่มสร้างจริง

Punch list ของสิ่งที่ต้องได้คำตอบ/เตรียมข้อมูล/ตั้งค่า ก่อนจะเริ่มพัฒนาแอปจริงได้เต็มรูปแบบ

## A. รอคำตอบจากป๊อป

- วงเงินตั้งต้นเงินสดย่อยจริง (จำนวนเงิน) และใครเป็นผู้ถือ
- รอบเติมเงินคืนกองทุนเงินสดย่อย (มีรอบตายตัวหรือเติมเมื่อใกล้หมด)
- รอบจ่ายคืนพนักงานจริง (เงินทดรองจ่าย) และวิธีจ่าย — โอนเข้าบัญชี / รวมในเงินเดือน / เงินสด
- เกณฑ์ตัดยอด ฿20,000 ในกรณีบิลคาบเกี่ยวจุดตัดพอดี (ดู [docs/02-requirements-from-pop.md](./02-requirements-from-pop.md#กติกาอัตโนมัติสำหรับจำแนกประเภทเงิน)) — ตัดทั้งใบเป็นประเภทเดียว หรือแบ่งสัดส่วน?
- **หมวดหมู่ + Cost Center + Acc name จริงจาก Odoo — บล็อกที่สุด** งานถัดไปแทบทั้งหมด (data schema, mapping, mockup ของหน้าเลือกหมวดหมู่) รอสิ่งนี้อยู่

## B. ข้อมูลที่ต้องเตรียมเอง

- โลโก้บริษัท TDFB เป็นไฟล์รูปจริง — ตอนนี้ในเทมเพลตเอกสารรับเงิน ("เอกสารรับเงิน") ยังเป็นกล่อง placeholder เปล่าอยู่
- รายชื่อซัพพลายเออร์ประจำ ทั้งภาษาไทยและภาษาอังกฤษ — ใช้ตั้งชื่อไฟล์เมื่ออัปโหลดเข้า Google Drive
- เลขบัตรประชาชนและรูปสำเนาบัตรของพนักงานแต่ละคน — ต้องมีหน้า "ตั้งค่าโปรไฟล์" ในแอปซึ่งยังไม่ได้ออกแบบ

## C. ตั้งค่าระบบภายนอก

- Google Drive root folder ปลายทางสำหรับเก็บไฟล์แนบ
- Slack webhook / bot token และช่องทางปลายทางสำหรับปุ่มแจ้งบัค
- ยืนยันโดเมน Google Workspace จริง (`@tdfb.co`) สำหรับใช้จำกัดสิทธิ์การล็อกอินเข้าแอป

## D. ขอบเขต

- ยืนยันว่าเฟสนี้ **ไม่เชื่อมต่อ Odoo ผ่าน API** — ข้อมูลยังคงต้องกรอกมือจาก Google Sheet เข้า Odoo อยู่
- ถ้าต้องการเชื่อมต่อ Odoo จริงในเฟสนี้ ต้องขอสิทธิ์ Odoo API เพิ่ม ซึ่งจะขยายขอบเขตงานไปอีกระดับหนึ่ง
