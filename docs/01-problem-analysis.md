# การวิเคราะห์ปัญหา (5-Why) — Expense Tracking

## บริบท

ก่อนเริ่มออกแบบระบบ ทีมได้ทำ 5-Why analysis เพื่อหา root cause ของปัญหาการบันทึกค่าใช้จ่าย (เงินสดย่อยและเงินทดรองจ่าย) ในปัจจุบัน โดยไล่จากอาการที่สังเกตเห็นได้ 3 สาย ซึ่งทั้งสามสายลงเอยที่ต้นตอเดียวกัน

## สายที่ 1: เวลาที่ใช้ในการทำงานมากเกินความจำเป็น

การบันทึกค่าใช้จ่ายแต่ละครั้งใช้เวลานานกว่าที่ควรจะเป็น เมื่อไล่ถามว่า "ทำไม" ต่อเนื่องหลายชั้น พบว่าสาเหตุลึกที่สุดคือการไม่มีเครื่องมือที่ทำงานได้ทันทีตอนหน้างาน ทำให้ข้อมูลต้องผ่านการพักไว้ชั่วคราวในหลายที่ แล้วค่อยมารวบรวมทีหลัง ซึ่งเป็นการทำงานซ้ำและเสียเวลาโดยไม่จำเป็น

## สายที่ 2: กรอกข้อมูลซ้ำซ้อน 2 รอบ

ข้อมูลค่าใช้จ่ายเดียวกันต้องถูกพิมพ์ลงไปสองที่คือ Google Sheet (สำหรับ track ส่วนตัว) และ Odoo (สำหรับบันทึกบัญชีจริง) เมื่อไล่ 5-Why ก็พบต้นตอเดียวกันคือไม่มีเครื่องมือกลางที่เชื่อมต่อกับ Odoo ตั้งแต่ต้นทาง ทำให้ Google Sheet ถูกใช้เป็น "ที่พักข้อมูล" ชั่วคราวไปโดยปริยาย แล้วต้องมาคีย์ซ้ำเข้า Odoo อีกรอบ

## สายที่ 3: ขั้นตอนแนบรูปเอกสารหลายขั้นตอน

การนำรูปใบเสร็จเข้าสู่ระบบต้องผ่านหลายขั้นตอน (ถ่ายรูป → ส่งเข้า Slack → เปิดคอมพิวเตอร์ → ดาวน์โหลด/แนบเข้า Odoo) ซึ่งไล่ 5-Why แล้วก็พบว่าลงเอยที่ต้นตอเดียวกันอีกเช่นกัน คือไม่มีเครื่องมือหน้างานบนมือถือที่รับรูปแล้วส่งต่อเข้าสู่ปลายทางได้โดยตรง ทำให้ Slack กลายเป็น "ที่พักรูป" ชั่วคราวไปโดยปริยายเช่นเดียวกับที่ Google Sheet เป็นที่พักตัวเลข

## Root Cause ร่วม

ทั้งสามสายปัญหาลงเอยที่จุดเดียวกัน:

> **ไม่มีเครื่องมือหน้างาน (มือถือ) ที่เชื่อมกับ Odoo สำหรับบันทึกข้อมูลทันทีตอนที่ยังไม่ครบ (draft)**

เพราะไม่มีเครื่องมือกลางที่รองรับการบันทึกแบบ "draft" ได้ตั้งแต่ต้นทาง (เช่น ตอนสั่งของยังไม่มีใบเสร็จ) พนักงานจึงต้องหาทางแก้ปัญหาเฉพาะหน้าด้วยเครื่องมือที่มีอยู่แล้ว — ใช้ **Google Sheet เป็นที่พักข้อมูลตัวเลข** และใช้ **Slack เป็นที่พักรูปภาพ** — ซึ่งเป็นสองระบบที่แยกขาดจากกันและแยกขาดจาก Odoo ทำให้เกิดขั้นตอน "ส่งต่อข้อมูลด้วยมือ" (manual hand-off) อย่างน้อย 2 ครั้งก่อนข้อมูลจะไปถึง Odoo จริง

## สาเหตุรอง (Contributing Causes)

นอกจากช่องว่างของเครื่องมือหน้างานแล้ว ยังมีจุดที่ต้องอาศัยการตัดสินใจของคนล้วนๆ โดยไม่มีเครื่องมือช่วยเลย ซึ่งเป็นสาเหตุรองที่ซ้ำเติมปัญหาเวลาและความผิดพลาด ได้แก่:

- **การเดาหมวดหมู่ค่าใช้จ่าย** — ต้องอ่านบิลแล้วตัดสินใจเองว่าเข้าหมวดไหนตามผังบัญชี Odoo
- **การแยก VAT** — ต้องคำนวณแยกก่อน VAT / VAT 7% / หลัง VAT ด้วยมือ
- **การจำแนกเงินสดย่อย vs เงินทดรองจ่าย** — ต้องจำเองว่ายอดสะสมของเดือนนี้เกิน ฿20,000 หรือยัง
- **เอกสารสำหรับบิลไม่สมบูรณ์** — บิลที่ไม่มีใบเสร็จแบบเป็นทางการ (เช่น ร้านสะดวกซื้อ) ต้องทำเอกสารรับเงินเสริมด้วยมือทุกครั้ง
- **การตรวจจับรายการซ้ำ** — ไม่มีระบบเตือนเมื่อมีคนบันทึกรายการเดียวกันซ้ำ ต้องอาศัยความจำและการตรวจสอบเองล้วนๆ

## ทิศทางการปรับปรุง

จาก root cause และสาเหตุรองข้างต้น แนวทางแก้ไขคือ:

1. **แทนที่ Google Sheet ในบทบาทที่พักข้อมูล** — สร้างเครื่องมือบันทึกบนมือถือให้เป็น "จุดพักข้อมูลเดียว" (single source of parking) ที่รองรับการบันทึกแบบ draft ได้ตั้งแต่ต้น
2. **แทนที่ Slack ในบทบาทที่พักรูป** — ให้อัปโหลดรูปจากมือถือเข้า Google Drive ได้โดยตรงจากแอป ไม่ต้องผ่าน Slack อีกต่อไป
3. **เสริมระบบอัตโนมัติ (automation) เพื่อลดภาระการตัดสินใจด้วยมือ**:
   - OCR ช่วยเดาหมวดหมู่ค่าใช้จ่ายจากบิล
   - คำนวณแยก VAT อัตโนมัติ
   - จำแนกเงินสดย่อย/เงินทดรองจ่ายอัตโนมัติตามเกณฑ์ ฿20,000/เดือน
   - สร้าง "เอกสารรับเงิน" อัตโนมัติสำหรับกรณีบิลไม่สมบูรณ์
   - แจ้งเตือนรายการซ้ำเป็น popup ทันทีตอนกด submit
