# Data Schema — 25 คอลัมน์

Schema นี้เป็น **ทั้งเลย์เอาต์ของ Google Sheet ปลายทางที่แอปซิงก์ข้อมูลเข้าไป และเป็นโมเดลข้อมูลของตัวแอปเองในเฟสนี้ด้วย** (ยังไม่มีฐานข้อมูลแยกต่างหาก) ไฟล์ template จริงอยู่ที่ [`templates/sheet/TDFB Expense Tracking - Sheet Template.xlsx`](../templates/sheet/TDFB%20Expense%20Tracking%20-%20Sheet%20Template.xlsx) สร้างจากสคริปต์ [`templates/sheet/build_expense_tracking_sheet.py`](../templates/sheet/build_expense_tracking_sheet.py)

คอลัมน์ที่มีเครื่องหมาย **★** คือกลุ่ม "ต้องมีตั้งแต่รอบแรก" ส่วนที่เหลือสามารถเพิ่มเข้ามาทีหลังได้

## ระบบจัดการ (system-managed — ห้ามแก้มือ)

| คอลัมน์ | ★ | คำอธิบาย |
|---|---|---|
| รหัสรายการ | ★ | รหัสอ้างอิงเฉพาะของแต่ละรายการ ระบบสร้างให้อัตโนมัติ ใช้จับคู่แถวตอนอัปเดตข้อมูล |
| วันที่บันทึกเข้าระบบ | ★ | Timestamp ที่รายการถูกสร้างขึ้นในระบบ (ไม่ใช่วันที่ในบิล) |
| ผู้บันทึก | ★ | ชื่อพนักงานผู้ถ่ายรูป/กรอกรายการนี้ |
| สถานะ | ★ | สถานะในไปป์ไลน์: รอตรวจ → ตรวจแล้ว → นับเข้าระบบ (หรือ ต้องแก้ไข) |

## ประเภทเงิน

| คอลัมน์ | ★ | คำอธิบาย |
|---|---|---|
| ประเภทเงิน (เงินสดย่อย/เงินทดรองจ่าย) | ★ | จำแนกว่ารายการนี้เป็นเงินสดย่อยหรือเงินทดรองจ่าย เลือกเองก่อน submit หรือระบบช่วยตัดสินตามเกณฑ์ ฿20,000/เดือน |

| คอลัมน์ | ★ | คำอธิบาย |
|---|---|---|
| ประเภทเอกสาร | ★ | ใบเสร็จรับเงิน / ใบกำกับภาษี / บิลเงินสด |
| เลขที่เอกสาร | ★ | เลขที่ใบเสร็จ/ใบกำกับภาษีตามที่ปรากฏในบิล |
| เลขที่ PO | | เลขที่ใบสั่งซื้อ ถ้ามี — เพิ่มได้ทีหลังถ้ายังไม่พร้อม |
| วันที่ในบิล (Date) | ★ | วันที่ตามที่ระบุในบิลเท่านั้น (ไม่ใช่ Due Date) ใช้ cross-check เอกสารจริง |
