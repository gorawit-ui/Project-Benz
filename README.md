# Expense Tracking | ระบบติดตามค่าใช้จ่าย

โปรเจกต์เว็บแอป (mobile-first) สำหรับทีม TDFB (Thai F&B company) เพื่อบันทึกและติดตามค่าใช้จ่ายแบบเรียลไทม์ ด้วยการถ่ายรูปใบเสร็จ → OCR/AI อ่านและช่วยจัดหมวดหมู่ → ผู้ตรวจทานยืนยันความถูกต้อง → ขึ้นแดชบอร์ดให้เห็นยอดใช้จ่ายทันที

## แนวคิดหลัก

พนักงานถ่ายรูปใบเสร็จผ่านมือถือ ระบบใช้ OCR + AI อ่านข้อมูลในบิลและเดาหมวดหมู่ค่าใช้จ่ายให้อัตโนมัติ โดยอ้างอิงผังบัญชีจริงของ Odoo จากนั้นผู้ตรวจทาน (reviewer) จะตรวจสอบความถูกต้องก่อนรายการจะถูก "นับเข้าระบบ" แดชบอร์ดจะแสดงยอดใช้จ่ายแบบเรียลไทม์ ระบบแยกติดตามเงินสองประเภทที่มีตรรกะต่างกัน คือ **เงินสดย่อย (Petty Cash)** ซึ่งเป็นวงเงินคงที่ที่แอดมินถือไว้และเบิกจ่าย-เติมเป็นรอบ และ **เงินทดรองจ่าย (Advance/Reimbursement)** ซึ่งพนักงานสำรองจ่ายเองก่อนแล้วบริษัทจ่ายคืนตามรอบ

**สำคัญ — ขอบเขตของเฟสนี้**: ระบบนี้ **ไม่ได้เชื่อมต่อ Odoo ผ่าน API โดยตรง** ข้อมูลจะไหลจาก การถ่ายรูป+OCR → แอปนี้ → ซิงก์อัตโนมัติเข้า Google Sheet (โครงสร้างคอลัมน์เหมือนกับแอปทุกประการ) → แล้วมนุษย์ยังคงต้องคีย์ข้อมูลจาก Sheet เข้า Odoo ด้วยมืออยู่ ประโยชน์หลักของเฟสนี้คือการตัดขั้นตอนกรอกข้อมูลซ้ำซ้อน (เดิมต้องพิมพ์ทั้งใน Sheet ส่วนตัวและใน Odoo) และทำให้เห็นยอดใช้จ่ายแบบเรียลไทม์ ซึ่งปัจจุบันไม่มีใครเห็นจนกว่าจะถึงรอบปิดบัญชี

## สำรวจเพิ่มเติม

- [`design/`](./design) — ม็อกอัพหน้าจอ UI ทั้ง 10 artboard (Login, Main, Review, Dashboard ฯลฯ) เป็น design canvas ที่ตีพิมพ์ไว้แล้ว
- [`templates/`](./templates) — เทมเพลต Google Sheet (schema 25 คอลัมน์) และเทมเพลตเอกสารรับเงิน (.docx)
- [`docs/`](./docs) — เอกสารวิเคราะห์ปัญหา, requirements, data schema, และ open items

## สถานะโปรเจกต์

โปรเจกต์นี้ยังอยู่ใน**ขั้นตอนวางแผนและออกแบบ (planning / mockup stage)** — ยังไม่มีโค้ดแอปที่ใช้งานได้จริง repo นี้เป็น **source of truth** สำหรับงานออกแบบ เทมเพลต และการตัดสินใจต่างๆ ที่จะใช้ต่อยอดเป็นแอปจริงในลำดับถัดไป
